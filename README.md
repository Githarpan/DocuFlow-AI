# DocuFlow AI

AI-powered GST invoice and document automation platform.

## Initial Features
- Purchase invoice processing
- Sales invoice processing
- PDF and image upload
- AI-based invoice data extraction
- GST validation
- Manual review and approval
- Excel export

## Technology Stack
- Java 21
- Spring Boot 3.5.x
- PostgreSQL
- Ollama
- Apache PDFBox
- Tesseract OCR

## Project Structure
- backend: Spring Boot application
- docs: Product and architecture documentation
